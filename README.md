# Obesity Evaluation & Management

Static HTML clinical decision-support application based on the provided Harrison Ch.402 material.

## Deploy to Vercel

Import this repository into Vercel with **Framework Preset: Other**, **Root Directory: /**, and no build command. The root `index.html` is the entry point.

## Clinical safety

For qualified clinician review. Verify clinical guidance, doses, contraindications, and drug availability against current primary sources before patient care.
